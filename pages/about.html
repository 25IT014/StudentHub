About StudentHub

Mission & Vision

StudentHub is a modern digital ecosystem crafted to eliminate campus friction. Designed under the Web Development Frameworks (ITUE203) syllabus at Charotar University of Science and Technology (CHARUSAT), it brings all essential campus services into a unified, intuitive, and accessible interface.

From prospective student registration to event organization, profile management, and live administrative moderation, StudentHub embodies best practices in modern web standards, accessibility (WCAG), and responsive design.

Key Capabilities

Feature Set

🔒 Secure Authentication

Bcrypt password hashing, PHP session fixation defense, RBAC, and remember-me tokens.

📅 Dynamic Event Hub

Fetch API integration, real-time search, filters, pagination, and poster uploads.

📊 Data Management

Full CRUD operations with MySQL PDO prepared statements, CSV exports, and audit trails.

♿ Accessibility First

Semantic HTML5 structure, ARIA labels, skip navigation links, and theme personalization.

Technology Architecture

Stack Overview

The project follows a clean decoupled structure:

  • Frontend: Semantic HTML5, CSS3 Grid & Flexbox, Vanilla JavaScript ES6+ (Fetch API, DOM manipulation).
  • Backend Processing: PHP 8.2 with Object-Oriented PDO connection, server-side data sanitization, and RESTful JSON APIs.
  • Database: Normalized MySQL schema (3NF) with primary keys, foreign key constraints, indexes, and audit logs.
  • Storage: Structured CSV / JSON file logs alongside relational MySQL tables.
