# StudentHub Portal
## 1. Problem Denition
Students need a single web portal to access academic and campus-related infor mation.
Currently, information about events, registrations, notices, student pro les, and fe edback may be available through di erent systems.
StudentHub will provide one centralized web portal for students and administrato rs.
## 2. Project Objectives
1.	Provide a single portal for students.
2.	Allow students to register and log in.
3.	Display college events and notices.
4.	Allow students to register for events.
5.	Allow students to manage their pro les.
6.	Provide an administrative management system.
## 3. User Roles
### 3.1 Student
e student can:

-	Login and logout
-	View the student dashboard
-	View and search events
-	Register for events
-	View and update pro le
-	View FAQ
-	Submit feedback
### 3.2 Admin
e administrator can:
-	Login
-	View the admin dashboard
-	Manage student records
-	Add, update, and delete events
-	View event registrations
-	View system activities
## 4. Functional Requirements
FR 01: 	e system shall allow a new student to register.

FR 06: 	e student shall be able to view and update pro le details.
